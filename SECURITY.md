# Security Policy

## Supported releases

MADI3D is currently distributed as a public beta. Security fixes are applied to the latest public beta and current development branch; older beta binaries may not receive backports.

## Reporting a security issue

Please report suspected security vulnerabilities privately to **developer@madi3d.org**.

Include the affected MADI3D version/build, operating system, reproduction steps, and any logs or files that can be shared safely. Do not publish exploit details, credentials, private datasets, or sensitive user information in a public GitHub issue before the report has been triaged.

Ordinary application bugs, scientific-correctness problems, and reproducible workflow failures that do not involve a security or privacy concern should be reported through the public GitHub issue tracker.
